## The concepts

### Monitoring AI Solutions
Monitoring involves continuously assessing the performance of AI solutions to ensure they meet business objectives. This includes tracking metrics such as accuracy, response time, and user satisfaction.

**Example:** A retail company uses an AI recommendation system. By monitoring the click-through rates and conversion rates, they can determine if the recommendations are effective and make adjustments as needed.

### Testing AI Models
Testing is the process of evaluating an AI model's performance before deployment. This includes validating the model against a test dataset to ensure it performs as expected.

**Example:** A financial institution tests its fraud detection model using historical transaction data to measure its accuracy and false positive rate before going live.

## Side by side

| Aspect                | Monitoring                          | Testing                             |
|-----------------------|-------------------------------------|-------------------------------------|
| Purpose               | Ongoing performance assessment      | Pre-deployment evaluation            |
| Frequency             | Continuous                          | One-time or periodic                |
| Metrics               | Accuracy, response time, user feedback | Accuracy, precision, recall         |
| Tools                 | Dashboards, alerts                  | Test datasets, validation frameworks |

## Exam traps
- Confusing monitoring with testing; remember that monitoring is ongoing while testing is typically a one-time process before deployment.
- Misunderstanding metrics; ensure you know which metrics apply to monitoring versus testing.
- Overlooking the importance of user feedback in monitoring AI solutions.

## Recap
- Monitoring is continuous assessment; testing is pre-deployment evaluation.
- Key metrics differ between monitoring and testing.
- User feedback is crucial in monitoring.

## Note for Experienced Copilot Users
Since you use GitHub Copilot daily, focus on:
1. **Domain 1** — Microsoft's specific 6 responsible AI principles (terminology matters)
2. **Domain 3** — Data flow and architecture (how Copilot builds prompts internally)
3. **Domain 2** — MCP, Agent Mode, Edit Mode, org-level policies (exam loves these)
4. **Domain 6** — `.copilotignore` specifics, content exclusion scopes, telemetry options
